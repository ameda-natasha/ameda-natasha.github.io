Day 1 - SOC Analyst Journey: Starting With the End in Mind

Today I officially started my 30-day intensive sprint to become job-ready
as an entry-level SOC Analyst. Rather than diving into tools immediately,
I started strategically - by studying the market first.

     What I did today

I analyzed 5 real entry-level SOC Analyst job descriptions to extract the
exact skills employers are hiring for right now. Then I set up my complete
working environment: GitHub portfolio, lab accounts, and a structured
daily tracking system.

     What the job market actually wants

After reading 5 job postings carefully, these are the 10 most frequently
required technical skills - ranked by how often they appeared:

  1. SIEM monitoring & log analysis (Microsoft Sentinel, Splunk, Elastic)
  2. EDR monitoring & endpoint security (Microsoft Defender)
  3. Alert triage - classifying false positives vs. true positives
  4. Windows & Linux system internals
  5. TCP/IP networking fundamentals
  6. Incident documentation & ticketing workflows
  7. Alert enrichment, IOC lookup & threat intelligence
  8. Phishing, malware & suspicious email analysis
  9. Scripting for automation (Python, Bash, PowerShell)
 10. MITRE ATT&CK framework familiarity

This list is now my 30-day curriculum. Every skill gets hands-on lab time,
a project, and documented proof of work.

     My current baseline

Honest self-assessment going into Day 1:

  ✅ Networking fundamentals - solid (TCP/IP, DNS, HTTP)
  ✅ Attack concepts - comfortable (phishing, malware, lateral movement)
  ✅ Linux terminal - regular user
  ✅ Wireshark - used hands-on
  ✅ SIEM exposure - Splunk/Elastic/QRadar (needs deeper fluency)
  🔄 Windows Event Log analysis - surface level, needs depth
  🔄 Incident response process - conceptual, not procedural
  ❌ Scripting - can read Python/Bash, cannot yet write independently
  ❌ Detection engineering - no experience yet
  ❌ Threat intelligence workflow - no hands-on yet

     What I built today

  • GitHub portfolio repository - live and public
  • 30-day roadmap committed and documented
  • Skill gap analysis mapped to real hiring requirements
  • Lab accounts active: TryHackMe, LetsDefend, CyberDefenders, Splunk

     Key insight from today

Most people preparing for cybersecurity roles study what they find
interesting. I'm studying what employers are actually paying for.
Starting with job descriptions instead of a course syllabus changes
everything about how you prioritise your time.
